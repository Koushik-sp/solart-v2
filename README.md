# solart-v2

SolarCharge Controller — an MVP simulation of a solar + battery energy
system with an **Admin** control side and an investor **User** side that
earns simulated "Project Credits".

The project lives in [`solar-charge-controller/`](solar-charge-controller/) —
see its [README](solar-charge-controller/README.md) for setup, demo
logins, the Project Credits system, and the earnings formula.

> This is an MVP simulation only. No real authentication, no real
> payments, no real cryptocurrency, no securities, and no real hardware
> integration. Project Credits are simulated demo credits — not real
> money and cannot be withdrawn.
